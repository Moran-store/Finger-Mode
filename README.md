# Finger Mode

### Your cursor. Your attitude. 🖕

A free browser extension that replaces your normal webpage cursor with a custom middle-finger cursor.

## 🖕 Download

**[Download Finger Mode v0.1.0](https://github.com/Moran-store/Finger-Mode/releases/download/v0.1.0/Finger-Mode-0.1.0.zip)**

## Features

- ON / OFF toggle
- Small / Medium / Large cursor
- Ctrl + Shift + F shortcut
- No account required
- No ads or analytics

## Installation

1. Download **Finger-Mode-0.1.0.zip** above.
2. Extract the ZIP file.
3. Open `chrome://extensions` in Chrome.
4. Turn on **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted **Finger Mode** folder.

## Compatibility

Works with Chromium-based browsers that support Manifest V3, including Chrome and Microsoft Edge.
